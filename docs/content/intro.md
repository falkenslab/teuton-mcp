# teuton-mcp

Teuton for AI agents: write, check and run infrastructure tests and read the results, through MCP.

It's an [MCP](https://modelcontextprotocol.io) server: an AI app (Claude Code, Claude Desktop, an agent built on [agent-kit](https://falkenslab.github.io/agent-kit/)) starts it and gets its tools. You don't call the tools yourself: you ask in your own words, and the agent picks them.

- **[Getting started](getting-started.md)**: install it in your AI app.
- **[Tools](reference/tools.md)**: every tool, with the description the agent reads.
- **[Releases](releases.md)**: what changed in each version.
